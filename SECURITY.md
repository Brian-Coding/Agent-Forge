# Security policy

Agent Forge runs coding agents with broad local permissions, so security reports matter. Please read the [safety model](docs/safety.md) for what is and is not in scope.

To report a vulnerability, use GitHub's **Report a vulnerability** button (private security advisory) on this repository. Please do not open a public issue for security problems.

Especially interesting: ways for a web page, another local user, or a crafted project file to drive Agent Forge, escape its guarded file operations, or make it stop processes it does not own.
