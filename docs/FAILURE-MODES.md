# Failure modes when supervising coding agents

Forge coordinates work; humans remain accountable for requirements, tests and release decisions. Provider permission prompts are disabled. Built-in instructions are behavioral guidance, not a filesystem or network sandbox.

| Failure | Specific guardrail | Regression evidence / remaining gap |
| --- | --- | --- |
| Reconnect sends the same command twice | [`command-session.ts`](../src/server/services/command-session.ts) caches request IDs and rejects changed payloads; [`command-queue.ts`](../src/server/services/command-queue.ts) serializes each queue. | [`command-session.test.ts`](../src/server/services/command-session.test.ts), [`message-queue.test.ts`](../src/client/message-queue.test.ts), [`command-queue.test.ts`](../src/server/services/command-queue.test.ts). Deduplication is process-local and limited by cache expiry/capacity; it does not survive restart. |
| Stale session is retried after it already changed files | [`chat.service.ts`](../src/server/services/chat.service.ts) marks retry unsafe after tool activity or checkpoints, retries clean stale sessions once, and resets session ownership on provider/model/project changes. | [`chat.service.integration.test.ts`](../src/server/services/chat.service.integration.test.ts): clean stale-session retry and no retry after tool calls; [`agent.service.test.ts`](../src/server/services/agent.service.test.ts). |
| Late events from a cancelled turn overwrite newer work | Turn epochs/identity checks in [`chat.service.ts`](../src/server/services/chat.service.ts) reject stale callbacks and discard queued continuations. | Chat integration test “cancellation drops queued work and late adapter callbacks cannot mutate state.” |
| Root process exits but grandchildren or inherited pipes remain | [`killProcessTree`](../src/server/utils.ts) verifies owned process groups; adapters unwind on root exit and cancellation. [`terminateIfOwned`](../src/server/services/process-ownership.ts) requires identity proof before startup cleanup. | [`adapter-process.integration.test.ts`](../src/server/agents/adapters/adapter-process.integration.test.ts), [`process-tree.integration.test.ts`](../src/server/process-tree.integration.test.ts), [`process-ownership.integration.test.ts`](../src/server/process-ownership.integration.test.ts). **Gap:** deliberately detached sessions can escape; native Windows/macOS unverified. |
| A port now belongs to a different process | [`handleKillPort`](../src/server/routes/ports.routes.ts) rechecks a short-lived selection token, listener and process birth identity. | [`ports.routes.test.ts`](../src/server/routes/ports.routes.test.ts). Final OS-level PID reuse race remains; only stop a listener you recognize. |
| Another web page connects to the local workbench | [`createNetworkGuard`](../src/server/network-guard.ts) enforces bound origin plus launch token on WebSocket and mutations; [`parseClientCommand`](../src/server/client-message.ts) enforces exact schemas. | [`network-guard.test.ts`](../src/server/network-guard.test.ts), [`client-message.test.ts`](../src/server/client-message.test.ts), [`browser-check.mjs`](../scripts/browser-check.mjs). Same-user local processes remain trusted. |
| Symlink tricks the harness into deleting unrelated files | [`safe-filesystem.mjs`](../src/server/services/safe-filesystem.mjs) checks lexical/real paths, root names, inventories, symlinks and quarantine before deletion. | [`safe-filesystem.test.ts`](../src/server/services/safe-filesystem.test.ts). This does not constrain shell commands executed by the provider. |
| Crash or malformed persisted state loses the workspace | [`persistence.service.ts`](../src/server/services/persistence.service.ts) normalizes bounded fields, saves atomically and preserves damaged state; exclusive process lock prevents concurrent writers. | [`persistence.service.test.ts`](../src/server/services/persistence.service.test.ts), [`process-lock.test.ts`](../src/server/services/process-lock.test.ts), [`durable-mutation.test.ts`](../src/server/services/durable-mutation.test.ts). |
| Provider silently substitutes a model or auth expires mid-turn | Adapters report the actual model; [`chat.service.ts`](../src/server/services/chat.service.ts) latches mismatches and bounds auth retries. | [`claude.test.ts`](../src/server/agents/adapters/claude.test.ts), chat integration auth/retry tests. CLI protocol changes still require live-provider validation. |
| Cost disappears or missing accounting looks like zero | [`reported-usage.ts`](../src/shared/reported-usage.ts) preserves unknowns; chat bridge records each finished run on the agent; session cards show input/output/cost independently of the context estimate. | [`reported-usage.test.ts`](../src/shared/reported-usage.test.ts), last-run accounting in chat integration tests, Claude aggregate reconciliation test. **Gap:** historical dashboard estimates are not bills; no enforced dollar cap. |
| Agent claims tests passed without running them | Durable completion records describe process outcome, not product correctness. | **Known gap:** Forge does not independently verify agent assertions. Run required checks yourself or use a separate verifier; review test output and diffs before approval. |
| Prompt injection in source/tool output changes the task | [`prompt-builder.service.ts`](../src/server/services/prompt-builder.service.ts) includes fixed safety instructions every turn. | [`prompt-builder.service.test.ts`](../src/server/services/prompt-builder.service.test.ts) checks assembly, not model compliance. **Gap:** no robust prompt-injection isolation or live adversarial evaluation. |
| Parallel agents overwrite shared files or multiply spend | Per-agent queues separate conversations; shared watchers coalesce observations. | Chat integration test “different agents run concurrently without sharing state.” **Gap:** no cross-agent filesystem transaction or merge scheduler. Give writers separate Git worktrees and require human integration. Set provider budgets separately. |

The [adoption playbook](ADOPTION.md) turns these limits into review checkpoints. [ADRs](decisions/README.md) explain the model and alternatives.
